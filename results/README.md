# Results

Committed evidence for every reported number. Nothing here is hand-edited.

## Layout

```
results/
├── eda/                 inventory.csv, summary.json, EDA figures
├── labels/              per-trip label coverage and alignment diagnostics
├── models/              model_comparison.csv, folds, selected_model.json
├── optuna/              study.db, trials.csv, best_params.json, history/importance plots
├── hmm/                 decoder tuning and classifier-vs-HMM comparison
├── integration/         all-trip runs, latencies, failures
├── maps/                interactive Folium HTML
├── figures/             report-ready PNG/PDF figures
├── screenshots/         UI and API terminal screenshots (no secrets)
└── logs/                experiment logs (no data or secrets)
```

## Naming

- One file per experiment, never overwrite: `<date>_<model>_<config>.csv` or a
  stable aggregate such as `model_comparison.csv`.
- Every CSV includes: `run_id`, `git_commit`, `seed`, `partition`, `model`,
  `config`, metrics, timings.
- Every JSON has a `generated_at` and the command that produced it.

## Evidence policy

- A number in `README.md`, `viva.md` or the report must point to a file here.
- Figures are generated by `scripts/` or `visualisation/` from these files.
- Do not commit raw data, model caches or secrets.
- Keep failed runs (marked `status=failed`); they are part of the experimental
  record.

## Quick checks

```bash
head results/models/model_comparison.csv
head results/eda/inventory.csv
python -c "import json;print(json.load(open('results/eda/summary.json')))"
```
